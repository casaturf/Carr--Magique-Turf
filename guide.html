🗒 Les 5 Pages du Site

Chaque course est présentée à travers 5 types de pages pour une analyse complète :

🏠 1. Tableau de Bord (Index)

Page d'accueil affichant toutes les réunions du jour. Cliquez sur une réunion pour accéder à ses courses. Utilisez le sélecteur de date pour consulter les analyses des jours précédents.

📎 2. Réunion

Liste toutes les courses d'une réunion avec les informations clés : discipline, distance, dotation, heure de départ et nombre de partants. Cliquez sur une course pour voir les détails.

👤 3. Participants

Tableau complet des partants de la course : numéro, nom du cheval, jockey, entraîneur, musique (historique des performances) et cote actuelle.

📊 4. Classement

Le classement Carré Magique Turf avec les alertes colorées. Affiche pour chaque cheval : rang, indicateurs de marché, tendance et recommandation.

⭐ 5. Recommandation

Page finale avec l'arrivée officielle (après la course), le TOP 8 Carré Magique et les formules de jeu pour le Tiercé, Quarté et Quinté+.

📖 Comment Lire le Classement

📊 Le Tableau de Classement

Le classement est le cœur de notre analyse. Voici comment interpréter chaque colonne :

Rang : Position du cheval dans notre classement. Le numéro 1 est notre favori principal.

N° : Le numéro de départ du cheval dans la course (utilisé pour vos paris PMU).

Indicateurs de marché : Les données collectées en temps réel sur ce cheval, reflétant le comportement des parieurs et l'évolution du marché.

Tendance : Représentation visuelle de l'évolution globale des indicateurs du cheval.

Alerte : Le code couleur VERT / JAUNE / ORANGE / ROUGE indiquant le niveau de confiance selon notre algorithme.

💡 Comprendre les Alertes

VERT = Cheval fortement recommandé — Signal de haute confiance
JAUNE = Outsider intéressant — Signal positif mais moins certain
ORANGE = À surveiller — Indicateurs mitigés
ROUGE = À éviter — Signal défavorable

🎯 Comment Utiliser les Formules de Jeu

La page Recommandation propose des formules prêtes à jouer :

🔒 TOP 8 - Sélection Principale

Ce sont les 8 chevaux que nous considérons comme les plus sérieux dans la course. La quasi-totalité des combinaisons gagnantes se trouvent dans ce groupe. Utilisez-les comme base pour vos jeux Tiercé, Quarté et Quinté+.

💪 Formule BASE

Constituée uniquement des chevaux en alerte VERTE. C'est la sélection la plus sûre. Idéale pour les jeux simples (Gagnant, Placé) et comme base de vos combinaisons.

💰 Formule CHAMP RÉDUIT

Combine les chevaux VERTS et JAUNES pour un bon rapport risque/gain. Recommandée pour les jeux combinés (Tiercé, Quarté) avec un budget maîtrisé.

🏆 ACCESSIT

Les chevaux classés juste après le TOP 8. Ils peuvent compléter vos combinaisons pour le Quinté+ si vous souhaitez élargir votre couverture.

❓ Questions Fréquentes

À quelle heure les analyses sont-elles disponibles ?
Les premières analyses apparaissent dès les premières collectes de données, généralement en début de matinée. Elles sont mises à jour toutes les 15 minutes et deviennent de plus en plus fiables à mesure que le départ approche.
Puis-je consulter les analyses des jours précédents ?
Oui, utilisez le sélecteur de date sur la page d'accueil pour naviguer entre les différentes journées de courses. Les arrivées officielles et les résultats sont également affichés pour les courses terminées.
Comment voir l'arrivée officielle d'une course ?
Rendez-vous sur la page "Recommandation" de la course concernée. Si la course est terminée et que les résultats sont disponibles, l'arrivée officielle apparaît en haut de la page dans un encadré vert.
Le site est-il adapté aux mobiles ?
Oui, toutes les pages du site sont responsive et s'adaptent aux écrans de smartphones et tablettes. Vous pouvez consulter vos analyses directement depuis l'hippodrome ou le point de vente PMU.
Quelles courses analysez-vous ?
Nous analysons l'ensemble des réunions PMU du jour : courses françaises (trot attelé, trot monté, plat, obstacles) et certaines courses internationales lorsque les données sont disponibles.
